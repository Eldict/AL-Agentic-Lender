# Data

| File | What it is |
|---|---|
| `synthetic_housing.csv` | **SYNTHETIC** data (2,000 made-up rows, `source` column = `SYNTHETIC`). Generated by `train_valuation.py`. Not real sales. |
| `market_context.json` | Hand-written static market and rate context with an `as_of` date. Edit by hand. |

The synthetic data is only there so the Valuation Agent has something to learn from in the demo.
To use real data (Daft.ie export, Property Price Register), change `load_dataset()` in
`al_ai/valuation_model.py` and re-run `python train_valuation.py`.
